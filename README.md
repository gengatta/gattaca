# VION — личный журнал

Первая версия сайта VION: авторский цифровой журнал на пересечении науки,
психологии, дома, ремесла и внимательного отношения к жизни.

## Структура

- `index.html` — главная страница
- `journal.html` — журнал с записями по рубрикам (с фильтром и разворачиваемым текстом)
- `about.html` — об авторе
- `candles.html` — свечи ручной работы VION
- `contact.html` — контакты
- `assets/css/style.css` — стили сайта
- `assets/js/main.js` — мобильное меню и фильтр рубрик в журнале

## Как посмотреть сайт локально

Просто откройте `index.html` в браузере — двойным кликом из папки,
никакой установки не требуется.

## Как опубликовать онлайн (GitHub Pages)

1. В репозитории на GitHub: **Settings → Pages**.
2. В разделе **Source** выберите ветку с сайтом и папку `/ (root)`.
3. Сохраните — через пару минут сайт будет доступен по ссылке вида
   `https://<аккаунт>.github.io/<репозиторий>/`.

## Что дальше

Все тексты в `journal.html`, `about.html` и `candles.html` — черновики-заглушки.
Их можно постепенно заменять на настоящие записи, фотографии и описания свечей.
