# gattaca — личный ассистент Катаржины в Telegram

Помогает упорядочить дела, которые летят со всех сторон: работа в России и США,
учёба, личное. Встречи и задачи можно прислать текстом, расписанием или фото
ежедневника. Бот раскладывает их по направлениям, пересчитывает время из других
часовых поясов и вовремя напоминает. По утрам присылает план на день, по воскресеньям
обзор недели.

## Что умеет

**Встречи** — просто сообщением, сохраняются сразу:

| Сообщение | Что поймёт бот |
|---|---|
| `25.10 18:30 Стоматолог` | 25 октября в 18:30 |
| `завтра в 10:00 созвон с Анной` | сегодня / завтра / послезавтра |
| `в пятницу 15:00 маникюр` | ближайшая пятница |
| `через 2 часа забрать посылку` | через N минут / часов / дней / недель |
| `созвон с клиентом в 10:00 по Нью-Йорку` | переведёт в её время: «17:00 (10:00 NY)» |
| `звонок 9:30 PT`, `встреча 18:00 мск` | поясы: по Москве, NY/ET, Чикаго/CT, LA/PT и другие |

**Задачи** — с дедлайном или без:

| Сообщение | Что поймёт бот |
|---|---|
| `сдать эссе до пятницы` | задача, дедлайн — конец пятницы |
| `отправить отчёт к 25.10`, `дедлайн 20.10 18:00 презентация` | задача с датой (и временем) |
| `задача: разобрать почту` | задача без срока — во «входящие» (/inbox) |

О задачах бот напоминает утром за 2 дня, за день и в день дедлайна. Под напоминанием
есть кнопка «✅ Сделано».

**Направления.** По умолчанию: 🇷🇺 Работа РФ, 🇺🇸 Работа США, 🎓 Учёба, 🏠 Личное.
Бот определяет направление сам («пара по маркетингу» — учёба, «по Нью-Йорку» — США)
или по тегу (`#сша`, `#рф`, `#учеба`, `#личное`). Под каждой записью есть кнопка 🏷,
чтобы поправить. Свои направления: `/areas add 💼 Фриланс`.

**Расписание целиком и фото записей.** Это распознаёт Claude (нужен `ANTHROPIC_API_KEY`,
по умолчанию самая дешёвая модель Haiku, доли цента за фото). Бот показывает
«Вот что я поняла» с кнопкой «Сохранить» и пропускает уже прошедшее.

**Уточнения.** Если у встречи нет времени или дня, бот переспросит. Ответить можно
текстом (`18:30`, `в пятницу`) или кнопками («Сегодня», «Завтра», «Без точного времени»,
«📥 Задача без срока», «Пропустить»).

**Сводки.** Утром приходит план на день по направлениям, просроченное и ближайшие дедлайны.
В воскресенье вечером приходит обзор недели: сколько сделано, хвосты, что впереди,
что лежит во «входящих».

### Семья

1. Катаржина пишет `/family`, бот даёт одноразовую ссылку-приглашение.
2. Мама открывает ссылку и сразу получает доступ (в `ALLOWED_USER_IDS` её добавлять не нужно),
   потом пишет `/name Мама`.
3. Дальше:
   - под каждым сохранённым событием есть кнопки «👤 + Мама» / «👥 Всей семье»;
   - в расписании можно сразу писать, для кого событие: «маме к врачу в пт 10:00»;
   - мама тоже может ставить события Катаржине;
   - напоминания получают все участники события;
   - при добавлении или удалении общего события остальным приходит уведомление.

### Команды

- `/today`, `/week`, `/list` — план на сегодня, на неделю, всё ближайшее (`/list сша` — одно направление)
- `/tasks` — задачи и дедлайны, `/inbox` — задачи без срока, `/done 12` — отметить выполненной
- `/delete 12` — удалить
- `/areas` — направления, `/tz Нью-Йорк` — свой часовой пояс
- `/reminders 1d, 3h, 15m` — когда напоминать о встречах
- `/digest 08:30`, `/weekly 19:00` (или `off`) — утренний план и воскресный обзор
- `/family`, `/family leave`, `/name Мама` — семья
- `/cancel` — отменить незаконченное добавление

Список команд для @BotFather → `/setcommands`:

```
today - План на сегодня
week - Неделя по направлениям
list - Всё ближайшее
tasks - Задачи и дедлайны
inbox - Задачи без срока
areas - Направления
tz - Мой часовой пояс
reminders - Когда напоминать
digest - Утренний план
weekly - Обзор недели
family - Семья: пригласить маму
name - Как меня называть
cancel - Отменить добавление
help - Подсказка
```

## Запуск

Бесплатно на Oracle Cloud: пошаговая инструкция в [DEPLOY_ORACLE.md](DEPLOY_ORACLE.md).
Ниже — короткая версия для любого сервера.

1. Создай бота у [@BotFather](https://t.me/BotFather) (`/newbot`) и скопируй токен.
2. Узнай Telegram id Катаржины — пусть она напишет [@userinfobot](https://t.me/userinfobot)
   (или напишет новому боту: если id не в списке, бот сам его подскажет).
3. Для расписаний и фото получи ключ Claude API на
   [console.anthropic.com](https://console.anthropic.com). Без ключа бот тоже работает,
   но понимает только простые сообщения по одному событию.
4. Скопируй настройки и заполни `BOT_TOKEN`, `ALLOWED_USER_IDS` и `ANTHROPIC_API_KEY`:

   ```bash
   cp .env.example .env
   ```

5. Запусти:

   **Docker (рекомендуется для сервера):**
   ```bash
   docker compose up -d --build
   ```

   **Или локально (Python 3.11+):**
   ```bash
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   set -a && . ./.env && set +a
   python -m assistant
   ```

6. Катаржина открывает бота в Telegram и нажимает **Start**.

Бот должен работать постоянно, чтобы отправлять напоминания, — подойдёт любой
маленький VPS. События хранятся в SQLite (`data/assistant.db`), так что
перезапуск ничего не теряет; напоминания, пропущенные пока бот был выключен,
придут после старта (если событие ещё не прошло больше часа назад).

## Разработка

```bash
pip install -r requirements-dev.txt
pytest
```

Структура:

- `assistant/parser.py` — разбор даты, времени, дедлайнов и тегов из русского текста (без нейросети)
- `assistant/zones.py` — часовые пояса («по Нью-Йорку», `/tz`)
- `assistant/areas.py` — направления и их автоопределение
- `assistant/ai.py` — распознавание расписаний и фото через Claude
- `assistant/storage.py` — SQLite: семья, события и задачи, участники, напоминания, настройки
- `assistant/bot.py` — команды Telegram, уточняющие вопросы, фоновые задачи
